Como ler este painel (clique para abrir)
Carteira
o grupo/rota de vendas responsável pelo cliente (ex.: RE.RIOVERDE, TROCA.GO).
Dias de atraso
calculado sempre com a data de hoje menos a data de vencimento — recalculado toda vez que você abre o painel, não fica parado na data em que a planilha foi gerada. Se ainda falta vencer, mostra os dias que faltam; se já venceu, mostra os dias de atraso.
Faixa de dias
agrupamento dos dias em intervalos de 0–30, 31–60, 61–90, 91–180 e +180 dias — os mesmos intervalos são usados tanto para o que ainda vai vencer quanto para o que já venceu, para facilitar a comparação.
Tipo de movimento
a natureza da venda ou lançamento (venda no atacado, troca de óleo, receita financeira, etc.).
Tipo de título
a forma de pagamento combinada (boleto, cartão, PIX, etc.).
Cruzamento
a aba "Cruzamentos" cria uma tabela comparando duas dessas categorias ao mesmo tempo — por exemplo, quanto cada vendedor responsável tem vencido em cada faixa de dias. Também é possível cruzar parceiro, tipo de título, movimento e renegociação. Quanto mais escura a cor, maior o valor.
